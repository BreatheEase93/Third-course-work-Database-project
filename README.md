# Relational Data Processor & DB Analyzer

Комплексный сервис для проектирования реляционных баз данных, управления миграциями и оптимизации сложных SQL-запросов.

## 🚀 Текущий функционал (Features)
- **Проектирование схемы:** Нормализованная структура таблиц (3НФ) с правильным использованием внешних ключей (`Foreign Keys`) и ограничений (`Constraints`).
- **Сложные выборки:** Оптимизированные SQL-запросы с использованием агрегатных функций, группировок (`GROUP BY`) и объединений таблиц (`JOIN`).
- **Индексация:** Реализация индексов для ускорения поиска по часто запрашиваемым полям.

## 🛠️ Стек технологий (Tech Stack)
- Python 3.10+
- PostgreSQL / MySQL (укажите вашу БД)
- SQLAlchemy / Чистый SQL (укажите, что используется)
- Alembic (для миграций)

## 🗺️ План развития проекта (Roadmap / Будущие улучшения)
* [ ] **Data Seeding & Stress Testing:** Написание скрипта генерации фейковых данных (100k+ записей через `Faker`) для замера скорости запросов.
* [ ] **Query Optimization:** Анализ тяжелых запросов через `EXPLAIN ANALYZE` и оптимизация композитных индексов.
* [ ] **ORM Integration:** Полный переход на SQLAlchemy 2.0 (Async) + Alembic для управления миграциями.
* [ ] **Docker:** Контейнеризация базы данных и скриптов инициализации для быстрого развертывания одной командой.
